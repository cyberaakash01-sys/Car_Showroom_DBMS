# Car Showroom DBMS Management System 🚗

A Python based Car Showroom Management System designed to manage cars, customers, employees, orders, payments and generate analytics reports.

## Features

- 🚘 Car Information Management
- 👥 Customer Management
- 👨‍💼 Employee Management
- 📦 Order Management
- 💳 Payment Management
- 📊 Data Analytics Visualization
- 🖥️ Tkinter Desktop GUI Application

## Technologies Used

- Python
- MySQL
- SQLAlchemy
- Pandas
- Matplotlib
- Tkinter

## Project Structure

Car_Showroom_DBMS
│
├── GUI
├── analytics.py
├── cars_information.py
├── customers.py
├── employees.py
├── orders.py
├── payments.py
├── dbms.py
└── main.py


## Setup Instructions

1. Clone this repository

2. Install required libraries

3. Create your own `config.py` file using `config_example.py`

4. Setup MySQL database

5. Run the application
